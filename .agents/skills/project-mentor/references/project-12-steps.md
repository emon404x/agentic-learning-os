# 12-Step Project Mentorship Protocol

1. **Understand Project Requirements**: Define functional and non-functional requirements clearly.
2. **Identify Necessary Technologies**: Select runtime, framework, database, and testing tools.
3. **Create Prerequisite Learning Plan**: Identify concepts the learner must grasp before coding each stage.
4. **Explain Architecture**: Provide a Mermaid architecture diagram showing component responsibilities and data flow.
5. **Divide Development into Stages**: Break implementation into 4 incremental, testable milestones.
6. **Teach Each Required Concept**: Explain the underlying pattern before writing code for a stage.
7. **Guide Implementation**: Provide scaffolding and checkpoints while keeping the learner in the driver's seat.
8. **Explain Each Important File**: Document the role and interactions of every key file in the project.
9. **Review Code**: Audit learner code for correctness, readability, edge cases, and security.
10. **Generate Tests**: Write unit and integration tests verifying happy paths and boundary conditions.
11. **Help Debug Errors**: Teach systematic hypothesis-driven debugging from tracebacks and logs.
12. **Evaluate the Completed Project**: Assess against the 4-part project rubric (modeling, correctness, testing, comprehension).
